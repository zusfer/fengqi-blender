一、软件与界面（1–10）

1. 快捷键按了没反应？ 先点击 3D 视口再按——Blender 的快捷键只对鼠标所在区域生效。其次检查：是否在中文输入法状态；是否缺少小键盘（勾选“模拟小键盘”）。

2. 界面被拖乱了，怎么恢复？ 文件 → 默认 → 加载工厂设置。或用 文件 → 默认 → 保存启动文件，把当前布局固化为下次打开的样子。

3. 找不到某个功能在哪？ 按 F3 打开操作搜索，输入关键词直接调用。这能解决大部分问题。

4. 想用中文界面，但教程都是英文的？ 编辑 → 偏好设置 → 界面 → 翻译 可切中文。但建议保留英文界面配合本书附录 C 的术语表——你会发现绝大多数教程术语都是英文，早晚要认识它们。

5. 打开 Blender 很卡？ 减场景复杂度：隐藏暂时不编辑的物体（大纲视图点小眼睛），或渲染预览时降低分辨率。建模阶段用实体模式（按 Z 循环切换）而不是渲染预览。

6. 为什么我的界面和教程里长得不一样？ Blender 版本不同，按钮位置会有调整；工作区标签（Layout/Modeling/Shading）也会改变界面。认准“区域职能”而不是“按钮位置”。

7. 左上角那个“物体模式”下拉框是什么？ 模式切换器，常用的有“物体模式”和“编辑模式”，Tab 键在两者间快速切换。

8. 不小心关掉了某个面板怎么办？ 视口边角有个小“+”/“◢”图标，拖动它可以把面板劈出来；或右键面板边缘选择恢复垂直/水平分割。

9. 时间轴/动画部分我用不到，能关掉吗？ 能。把时间轴面板拖到几乎消失（拖它的边缘），或给它换个工作区——不影响建模。

10. 为什么按 A 没有全选，而是弹出了菜单？ 先确认当前是不是在 3D 视口里，且不在文本编辑器等区域。另外编辑模式里 A 是全选顶点/边/面——逻辑相同。

二、操作与变换（11–20）

11. 物体跟着鼠标乱飞怎么办？ 那是 G/R/S 进行中的正常状态。左键 = 确认，右键或 Esc = 取消回到原位。

12. 移动完了想改数字？ 左下角操作面板或按 F9，可回头精调刚刚操作的参数。

13. 新添加的物体为什么不在原点？ 新物体出生在 3D 游标处。Shift+C 把游标归零后再添加；或 Shift+右键 指定出生点。

14. 复制物体后分不开（重叠在一起）？ Shift+D 复制后副本贴合鼠标，立刻 G 移开即可。已经原地重叠了就先点选一个，G 拖走。

15. 缩放/旋转值能不能“清零”？ Ctrl+A → 全部变换，把变换“焊死”进网格（导出前必做）。Alt+G/R/S 只清除对应单项。

16. 为什么旋转时物体是绕一个奇怪的点转？ 旋转绕“物体原点”进行。想绕指定点转：先把 3D 游标放到该点（Shift+右键），然后在变换菜单里把旋转轴心设为“3D 游标”。

17. 坐标系里“全局”和“局部”是什么？ 全局 = 世界坐标系（三色固定方向）；局部 = 物体自己的坐标系（随物体旋转）。变换中连按两下轴键（如 G X X）可切换两种坐标系。

18. 怎么沿竖直方向精确移动 0.5 米？ 选中物体，G Z 0.5 Enter。

19. 为什么有时候点了左键反而取消了操作？ 进行中的变换里，左键是“确认”。你可能想点按钮却不小心点在视口里——操作完成后再点界面。

20. 撤销步数不够用？ 编辑 → 偏好设置 → 系统 → 撤销步数调大（默认 32，可到 256）。但别忘了手动的“另存新版本”永远是最稳档。

三、建模与编辑模式（21–30）

21. Tab 进不去编辑模式？ 先左键选中一个网格物体（大纲视图里点名字最稳），再按 Tab。

22. 挤出后模型乱成一团？ E 之后必须先按轴向键（Z/X/Y）再移动。乱了就 Ctrl+Z 重来，慢一点、先按 Z。

23. 为什么点不中想要的面/顶点？ 视角问题。转个角度让要操作的面朝向自己；或按 小键盘 7 俯视辅助定位。还可以在编辑模式按 Alt+Z 开启 X 光透视，穿过去选中被挡住的点。

24. 倒角 Ctrl+B 没反应？ 需要在编辑模式且选中了边。先在 3D 视口里操作。

25. 环切 Ctrl+R 放不上去？ 把鼠标“横跨”在你想切的一圈面上滚动滚轮，出现紫色预览线后再点击确认。

26. 模型渲染出来有黑面？ 法线朝向乱了。编辑模式 A 全选 → Shift+N 重算法线。

27. 两个点“粘”在一起分不开？ 把问题点选中，按 M → 按距离合并——它们本来就是重叠点，合并即可。

28. 布尔运算后模型脏乱？ 让两个物体“真相交”（不要表面完全重叠）；布尔完用 M 按距离大扫除一遍。

29. 怎么在两点之间连一条边？ 编辑模式选中两个顶点 → F（连接成面）或 J（连接顶点路径）。

30. 比例编辑 O 是干嘛的，什么时候用？ 让变形像捏橡皮泥一样带“柔性过渡”，适合调大形（圆顶、曲面）；滚轮能调影响半径。

四、材质、灯光、渲染（31–40）

31. 改了材质没效果？ 确认三件事：选中的是目标物体；改的是该物体挂着的材质；视口的着色模式不是“线框”。

32. 金属材质总是黑乎乎的？ 金属靠反射显形。加灯、提亮世界背景（世界属性 → 背景色），或先在材质预览模式下观察。

33. 渲染全黑怎么办？ 最常见三种：没灯；相机对着空处（先按小键盘 0 检查相机视角）；世界背景和物体会黑进黑。逐个排除。

34. Eevee 和 Cycles 到底怎么选？ Eevee 快（秒级），效果已够 90% 的场景，本书渲染配图都用它；Cycles 慢但更物理真实（玻璃、金属反射更准）。新手先用 Eevee。

35. 渲染有很多噪点/颗粒？ Cycles 采样不够：调高 Samples（如 128→512）或开启降噪。Eevee 一般没这个烦恼。

36. 阴影特别硬/特别糊？ 面光的“尺寸（Size）”决定阴影软硬：小尺寸 = 硬阴影，大尺寸 = 软阴影。

37. 背景想要纯白/透明？ 世界属性里把背景色调白；想要透明底（PNG 通道）：渲染属性 → 胶片 → 勾选“透明”。

38. 材质颜色调成纯白显得很假？ 真实世界几乎不存在纯白。用 0.85 左右的浅灰白 + 一点粗糙度，质感立刻上来。

39. 想让招牌发光怎么做？ 材质里把“发光颜色（Emission Color）”设为想要的色彩、“发光强度（Emission Strength）”给 2～5（夜晚场景）。

40. 相机怎么拍“背景虚化”？ 相机属性 → 景深（Depth of Field）→ 对焦目标设为物体（吸管点一下）或调焦距距离。

五、文件、导出与工程（41–50）

41. .blend1 是什么，能删吗？ 上一版自动备份。建议保留最近一两版，它是你的后悔药。

42. 导出给 Unity/UE 用什么格式？ FBX（或 GLB）。注意统一缩放单位（常见坑：差 100 倍）。

43. 模型在别的软件里躺倒了？ 坐标系 up 轴不同（Y-up vs Z-up）。在导出/导入设置里调 up 轴，或对方软件里转 90°，不要重做。

44. 导出后没有材质/贴图？ OBJ/STL 材质支持有限；用 GLB 或 FBX。贴图尽量“打包进文件”，别依赖绝对路径。

45. 导出后修改器效果没了？ 导出设置里勾选“应用修改器（Apply Modifiers）”，或导出前手动应用。

46. 文件越来越大、越来越卡？ 清理：删除无用物体；M 按距离合并；减少“细分”等级；删除孤立数据（大纲视图右上角下拉 → 孤立数据）。

47. 怎么把 A 文件里的物体搬到 B 文件？ 在 A 里选中 Ctrl+C，到 B 里 Ctrl+V。或 文件 → 追加（Append），从别的 .blend 里“取”物体/材质。

48. 场景里几百个物体怎么管理？ 大纲视图建集合（右键 → 新建集合）分组；M 移动物体进集合；命名用统一前缀（桌面_、桌腿_）。

49. 渲染一批视角图，一张张摆相机太慢？ 学第 8 章的无头渲染：脚本里一次摆好多个相机 → blender --background 批量出图。

50. 学完这本书下一步干什么？ 把三个综合项目各做 3 个变体（换配色、换时间、换布局）；然后挑一个自己真心喜欢的东西（你的键盘、你的球鞋、你的房间），照着参考图从头到尾做一次——那就是你的毕业作品。详见附录 D。
