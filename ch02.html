第 2 章 必会操作：你的第一个小时

场景：这一小时不学建模，只练"驾驶技术"。学完它，你能让任何物体在 3D 空间里精确地到你想要的位置——这是后面所有章节的地基。

学完你会

  • 熟练使用变换三件套：移动 G、旋转 R、缩放 S；
  • 用轴向约束把操作锁定在 X / Y / Z 单轴上；
  • 用数值输入做"毫米级"精确操作；
  • 掌握选择系统的组合拳，能快速选中想选的东西。

核心概念：变换（Transform）与坐标轴

3D 世界里只有三种"挪动"方式，称为变换：

变换 快捷键 生活比喻
移动（Move/Grab） G 把桌子搬到别处
旋转（Rotate） R 把桌子转个方向
缩放（Scale） S 把桌子改大改小

每个变换都发生在坐标系里。记住右手边这个"三色轴"：

  • 红色 = X 轴（左右方向）
  • 绿色 = Y 轴（前后方向）
  • 蓝色 = Z 轴（上下方向，Blender 里朝上的轴）

图 11　场景里的三色轴：红 X、绿 Y、蓝 Z。下面四个图请对照看

跟着做 1：G / R / S 三连

打开 Blender（如果上一个场景还在，按 Ctrl+N 新建一个干净的）。

① 移动（Grab）

  1. 左键点击立方体选中它；
  2. 按 G（Grab 的缩写），然后只移动鼠标——立方体会跟着跑，注意此时不要点击；
  3. 左键点击 = 确认；右键 / Esc = 取消（把方块放回原位）。这两个"后悔键"之后每次变换都通用。

图 12　按 G 后移动鼠标，立方体沿鼠标方向移动（图中向右移动到 X 轴正方向）

② 轴向约束——本课重点

刚才的移动是"跟着鼠标随便跑"。要沿单轴精确移动，在按 G 之后、点击确认之前，再按一下轴键：

  • G 然后按 X：只沿 X 轴移动（红轴方向）
  • G 然后按 Y：只沿 Y 轴
  • G 然后按 Z：只沿 Z 轴（上下方向）

再按一次同一个轴键 = 切换到"排除该轴"；按 Shift+X = 在 YZ 平面上自由移动（排除 X 轴）。

③ 数值输入——精确操作

Blender 的变换支持直接打数字：

G  X  1.5  Enter    → 沿 X 轴精确移动 1.5 米
R  Z  45   Enter    → 绕 Z 轴精确旋转 45 度
S      2    Enter    → 整体放大到 2 倍

【跟着做】把立方体沿 X 轴移动 1.5 米，再撤销回原位（Ctrl+Z）。

④ 旋转（R）

  1. 选中立方体，按 R，移动鼠标——它在转了；
  2. Esc 取消。再按 R、Z、输入 45、Enter——绕竖直轴精确转 45 度。

图 13　绕 Z 轴旋转 45 度（俯视时能看到明显转动）

⑤ 缩放（S）

  1. 选中立方体，按 S，移动鼠标——变大变小；
  2. S X 1.5 Enter = 只在 X 方向拉长 1.5 倍（长条效果）。

图 14　整体放大 1.6 倍后的样子

跟着做 2：选择系统的组合拳

操作 效果
左键点击 选中一个物体
Shift + 左键 加选 / 减选（在已选中上再点一次 = 取消）
A 全选（再按一次 = 取消全选）
Alt + A 全部取消选择
B 后框选 拉一个矩形框，框内的都被选中

【跟着做】

  1. 用 Shift+A（添加菜单）→ 网格 → 球体，加一个球；
  2. A 全选 → 立方体和球都亮了；
  3. Alt+A 全取消 → 再单独左键点球选中它；
  4. 按 X（删除菜单）→ 删除 → 球没了。Ctrl+Z 能把它救回来。

💡 添加物体的位置规律：新物体总是出现在3D 游标（那个红白小圆圈）所在的位置。如果新加的物体总是不在原点：Shift+C（把游标归零并全览视角），或 Shift+右键 点地面把游标放过去，再加物体。这是新手最常问的"我的新物体去哪了"。

跟着做 3：综合小练习——搭一张"小凳子"

用刚学的技术搭出以下结构（不用追求好看，练手感）：

  1. Shift+A 加一个立方体，S 0.8 Enter 缩小一点；
  2. G Z 0.5 Enter 抬高到半空——这是"凳面"；
  3. Shift+A 再加一个立方体，S 0.15 Enter 缩成小柱子；
  4. G X 移动它到凳面一角下方，再 G Z 调整高度顶住凳面；
  5. 再添加三条腿（可以复制现成的腿：选中后 Shift+D 复制，G 挪位置）。

Shift+D 是复制物体的快捷键：复制出来的副本会粘着鼠标，G 或直接点击决定放哪。以后你想"再要一个一样的"，就靠它。

图 15　摆完大概是这样一棵"独腿凳"，四项操作全用上了，这就够了

进阶一点：变换的数值面板

每次做完操作（比如刚移动完），左下角会弹出一个小面板（或按 F9 呼出），里面是该次操作的参数：移动了多少、旋转了几度，都可以回头精调。这就是为什么 Blender 允许你"先粗略做，再精确改"。

另外，视口右侧按 N 打开的**侧栏（Sidebar）**里，能看到并直接修改选中物体的位置/旋转/缩放数值——需要"把坐标输入成 0.35 这种"的时候，这里是操作台。

进阶一点：世界轴、局部轴与"尺寸 ≠ 缩放"

世界轴 vs 局部轴。 变换时再按一次同一个轴键（比如 G X X），约束就从"世界的 X"切换成"物体自己的 X"。物体被旋转过之后，按它"自己的方向"移动会顺手得多——视口顶部会显示当前用的是全局还是局部。

尺寸 ≠ 缩放。 按 N 打开侧栏看看："尺寸"是物体实际多大，"缩放"是相对原始网格的倍率。被 S 随意缩过的物体，缩放值不是 1——平时没感觉，但后面加修改器（尤其倒角和厚度）时容易出怪结果。

收尾习惯：Ctrl+A → 缩放。 对用 S 改过大小的物体，选中它 → Ctrl+A → 缩放：外观一点不变，缩放值变回 (1, 1, 1)，等于把"这次缩放"焊进网格。建模告一段落、准备加修改器之前，顺手做一遍。

图 16　真实软件截图：N 面板里缩放是 (0.5, 0.5, 0.25)——这是倍率，不是实际尺寸

图 17　Ctrl+A → 缩放之后：外观没变，缩放值全变回了 (1, 1, 1)

新手常见坑

坑 说明 对策
按 G 之后物体跟着鼠标乱飞 正常！此时还没确认 左键确认 / 右键或 Esc 取消，别慌着乱点
移动完了才想改数值 已确认的操作可以救 左下角面板（或 F9）改参数
新加的物体总是歪的/偏的 3D 游标不在原点 Shift+C 归零游标后再添加
Shift+D 复制的和在原地分不开 副本和原件完全重叠 复制后立刻 G 移开
缩放后导出别的软件比例不对 缩放值没有"应用" 见上一节：Ctrl+A → 缩放，一步解决
键盘没小键盘、1/2/3 没反应 或者是你正在中文输入法下 切英文输入法；没有小键盘就勾选"模拟小键盘"

过关标准

  • 我能说出框选两个方向的区别，并用"右往左"快速选走一堆零星小物体；
  • 我能开着 F8 正交 + F3 捕捉，用三种方式（相对坐标 / 直接输距离 / 捕捉咬点）精确给尺寸；
  • 我知道"尺寸"和"缩放"的区别，并对缩放过的物体做过一次 Ctrl+A → 缩放。

自检题

  1. 把物体沿 X 轴精确移动 2 米，写出完整按键序列。
  2. G 之后按了 Z，物体还能在水平面移动吗？为什么？
  3. 复制物体的快捷键是什么？和选中物体的快捷键有什么区别？
  4. 新添加的物体不在原点，最可能的原因和最短修复方法？

答案见文末。

自检题答案

  1. 选中物体 → G → X → 2 → Enter（X 对应红色轴；若按了 Z 就是竖直方向了）。
  2. 不能。按 Z 后移动被锁定在 Z 轴（竖直方向）；再按一次 Z 反而会排除 Z 轴变成水平移动，Shift+Z 也是排除。
  3. Shift+D 复制；A 全选——注意别记混，一个是 Duplicate 一个是 All。
  4. 3D 游标不在原点；按 Shift+C 把游标归零。

小结

  • 变换三件套：G 移、R 转、S 缩；左键确认，右键/Esc 取消。
  • 锁轴：G/R/S 后按 X/Y/Z 单轴，Shift+轴 排除该轴。
  • 数值输入：变换中直接打数字再回车，指哪打哪。
  • 选择：左键选、Shift加减、A全选、Alt+A清空、B框选。
  • 复制 Shift+D；后悔 Ctrl+Z；改参数 F9 或左下角面板。
  • 游标决定新物体出生点：Shift+C 归零。
